[47] (Normal) 
[48] (论文一级标题) 摘  要
[49] (Normal) 
[50] (Normal) 图像处理算得上是计算机视觉和人工智能的一项基础技术，医疗影像、工业检测、安防监控以及自动驾驶等领域，都能见到它被普遍用到的身影；不过，传统的图像处理课程，多数还是靠数学公式配上静态图片来讲授，算法原理本身就比较抽象，处理过程也没法直观地摆出来，初学者学起来会觉得吃力，最后的学习效果往往不太理想，那么在图像处理教学当中，怎样把抽象的算法转成能交互、能看得到的形式，从而把学习门槛降下来，就是一个急着要解决的问题。
[51] (Normal) 针对上面提到的问题，实现了一项基于OpenCV和Streamlit的图像处理算法交互式演示系统。平台里面一共集成了滤波、图像增强、边缘检测、形态学操作、阈值分割、图像变换等七大类和34种常用算法，用户可以通过滑块、下拉框这类组件去实时调节参数，处理的效果也会同步给出预览。开发语言为Python，图像处理算法由OpenCV来负责落地的，Web交互界面的搭建则交给了Streamlit，可视化的任务就落到了Matplotlib上。对于那些重点算法，本文还安排了中间过程可视化、直方图对比、频域分析之类的教学视图，算法原理、核心代码、参数说明还有应用场景的介绍，也都配套地写了出来。整个系统是按照四层模块化的思路来组织的，图像缩放、结果缓存这些机制用来改善响应性能。从测试数据来看，12种代表性算法的平均处理耗时约为3.7ms，中位数约为1.8ms，低于300ms的实时性指标算是达标，各个模块运行较为稳定，对图像处理课程的课堂教学以及学生的自主学习，都能起到不错的辅助作用。

[58] (Normal) Abstract
[59] (Normal) 
[60] (Normal) Image processing is a fundamental technology in computer vision and artificial intelligence, widely applied in medical imaging, industrial inspection, security monitoring, autonomous driving, and other fields. However, traditional image processing courses often rely on mathematical formulas and static image explanations, abstract algorithmic principles, and cannot intuitively demonstrate the processing process, making it difficult for beginners to understand and resulting in poor learning outcomes. How to transform abstract algorithms into interactive visual forms and lower the learning threshold is an urgent issue to be addressed in image processing teaching.
[61] (Normal) To address this, this paper designs and implements an interactive demonstration system for image processing algorithms based on OpenCV and Streamlit. The system is developed using Python, relying on OpenCV to implement image processing algorithms, building a web interface with Streamlit, and completing visualization using Matplotlib. The platform integrates three common algorithms: filtering, image enhancement, edge detection, morphology operations, threshold segmentation, and image transformation, supporting real-time parameter adjustment and preview effects of components such as sliders and dropdown frames. For key algorithms, it provides intermediate process visualization, histogram comparison, frequency domain analysis, and other teaching views, along with algorithm principles, core code, parameter explanations, and application scenario introductions. The system adopts a four-layer modular architecture, enhancing response performance through mechanisms such as image scaling and result caching. Tests show that the algorithm takes about 3ms to process in average time, meeting real-time performance indicators below 300ms. Each module runs stably, effectively supporting image processing course teaching and self-directed learning, making it highly practical.

[75] (Heading 2) 研究背景与意义
[76] (Normal) 计算机技术与人工智能发展迅速，图像处理技术也被推动从早期实验室研究，慢慢走到了大规模工程应用的阶段。在医疗这块，医学图像增强和分割技术被普遍用到了CT、MRI影像的辅助诊断上；工业领域中，基于机器视觉的表面缺陷检测，让产品质量检验的效率和精度都明显提上来了；安防方面，目标检测与跟踪技术也已经成为智能视频监控的核心支撑。
[77] (Normal) 随着图像处理技术的应用面扩大，相关人才的需求也跟着持续上涨。这门课理论性偏强，数学推导较复杂，教和学都不易。灰度变换、空域滤波、频域变换、边缘检测这些算法的核心思想，一般都借助卷积、梯度、傅里叶变换之类的数学工具来进行描述，初学者如果只靠公式推导和静态图像，很难把算法的处理过程在脑子里形成直观的理解。在传统的图像处理教学模式下，教材里的静态示例图像是学生感知算法效果的主要途径，他们既没法实时看到参数调整给处理结果带来的动态变化，也很难把算法内部中间的处理流程和核心逻辑把握得更深入。这种偏重理论、轻视直观的教学方式，把学习效率拉低，学生的学习兴趣也受到了一定影响。
[78] (Heading 2) 国内外研究现状
[79] (Normal) 图像处理教学工具的发展能理出两条比较清晰的脉络：在载体上，是从桌面端往Web端迁移；在功能上，是从结果展示型的静态演示，转到支持参数调节、还能即时反馈的交互式探索。早期的图像处理教学平台，大多是以MATLAB以及它的GUI工具为基础搭起来的，靠可视化界面把多种经典算法集成到一块，处理结果可以直观地展现出来，参数也能交互调节。不过这类平台虽然算法库挺丰富、开发也方便，但是它依赖商业软件，可移植性较差，网络化传播也就受到限制。
[80] (Normal) 随着开源计算机视觉库OpenCV不断普及，以它为底座搭建图像处理平台和工程应用渐渐成了主流做法。较早的工作来自贾小军等人，他们介绍了用OpenCV做图像处理的方法，图像平滑、边缘检测等方面的应用也被展示出来[1]。近些年来，OpenCV在大量工程领域被普遍拿来使用。在智能交通方向，迟盛元等人做出了车辆压线行为检测系统[2]，车道线识别算法则由李婷等人展开研究[3]；在农业方向，除草机器人的图像处理用到了OpenCV（刘立强等人）[4]，水稻考种的自动化图像分析由张侃等人完成[5]，鲜食毛豆的形貌特征被薛文等人提取出来[6]；在工业检测方向，浮法玻璃完整性检测系统由蒋碧萱等人构建[7]，熊宇奇等人针对SLM成形TC4合金做了缺陷识别[8]，LED针脚夹角偏差的视觉检测方法由唐健提出[9]，支撑剂颗粒的圆度和球度则被曹磊等人测量[10]；在安防与识别方向，基于嵌入式和OpenCV的智能视频监控系统受到杨蕊遥的研究[11]，银行卡卡号识别由兰帅丹等人完成[12]，轻量级蘑菇种类识别系统出自同佳欣等人之手[13]，水果识别系统由李锋霞等人搭建[14]，人脸黑头识别算法也被何祥芝等人做了探究[15]。除此之外，图像处理软件由李振杰等人设计[16]，图像识别与智能定价系统由陈凯文等人完成[17]，污水处理混凝监控系统由阳甜欣等人开发[18]，多特征融合检测算法受到李储成等人的研究[19]，图像处理被黄婧等人用于多孔介质孔隙结构分析[20]，水尺识别系统由韩轶菲等人开发[21]，绿幕背景视频抠图则由赵洁等人实现[22]。这些应用串起来看，OpenCV称得上通用图像处理工具，能力够强，适用范围也够广。
[81] (Normal) 在国际上，Streamlit已经被不少数据探索、机器学习模型演示还有教学辅助的场景应用上。它提倡"用纯Python来写交互式Web应用"，数据应用和可视化工具的开发门槛也就因此降下来。这套框架都是近几年才慢慢成熟起来的，教学类的交互系统也就多了一条轻量且能快速搭起来的路线。而在更早的时候，这类系统的界面普遍是架在Qt／PyQt桌面框架上的，功能虽然挺完备，可开发周期偏长，跨平台部署也较为麻烦。
[82] (Normal) 将现有的研究放到一起比较一下，还是能看出若干不足。一是算法的覆盖不够全面，多数平台只集成了十几种基础算法，教学大纲对算法体系提的那些要求，很难被完整覆盖到；二是算法中间处理步骤的可视化展示比较缺，算法内部的处理机制也就难以被揭示出来；三是教学辅助功能偏薄弱，原理说明、参数解释和代码展示常常各说各的、相互割裂，没有拧成一个有机的整体。针对这些不足，本课题把一套综合性图像处理算法交互式演示系统给构建了出来，该系统覆盖了七大类、34种算法，把实时交互和步骤可视化融合到一块，还配上了完整的教学辅助功能。
[83] (Heading 2) 主要研究内容
[84] (Normal) 本课题的研究工作主要围绕以下几个方面展开：
[85] (Normal) （1）图像处理算法库的构建。按照图像处理课程的知识体系来划分，常用的算法被分成滤波、图像增强、边缘检测、形态学操作、阈值分割、图像变换等六大类经典算法，另外还有一类深度学习算法，总共34种算法的处理功能，都是基于OpenCV和PyTorch来实现的。
[86] (Normal) （2）交互式参数调节机制的实现。针对每一种算法，都设计出滑块、下拉菜单、单选按钮等这类交互组件，参数可以由用户实时调节。
[87] (Normal) （3）算法步骤可视化与教学辅助功能的设计。对关键算法来说，中间处理步骤、直方图变化、伽马曲线以及频域分布这些数据曲线，都通过Matplotlib动态地展示出来。
[88] (Normal) （4）系统性能优化与测试验证。系统的响应速度由图像自动缩放、结果缓存、参数变更检测这些策略保障，系统的有效性和稳定性，则通过功能测试和性能测试验证。

[93] (论文一级标题) 相关技术与理论基础
[94] (Heading 2) 图像处理基础
[95] (Normal) 在计算机里，数字图像按矩阵形式存储。彩色图像表现为红、绿、蓝三个通道的二维数组叠加，数组中每个元素对应一个像素的强度值；灰度图像则只用一个二维矩阵表示，矩阵里的每个元素对应一个像素的灰度值，取值一般落在0到255之间。由此看来，所谓图像处理，本质上是对这些数值矩阵做运算，靠卷积、变换、阈值化等数学手段把图像增强、特征抽取和信息分析完成。谈到数字图像处理的系统理论，冈萨雷斯等人的经典教材讲得全面而深入，基本概念、空域与频域处理方法，和图像增强、复原、分割等技术都有阐述[26]；《数字图像处理学》由阮秋琦编著，图像处理的知识体系在其中被从教学角度系统梳理[27]；章毓晋的《图像工程》走得更远，图像处理、图像分析和图像理解的完整框架被从工程应用层面构建起来[28]。上述著作在很大程度上构成本课题的理论基础。
[96] (Normal) 图像处理算法数量多、种类杂，按处理目的和数学方法划分的话，空间域处理和频率域处理两大类基本可以覆盖。空间域处理在像素值上直接动手，灰度变换、空域滤波、直方图处理都归在这一类；频域方法的思路不一样，图像先经傅里叶变换被映射到频率域，滤波或加权处理施加在频谱系数上，随后靠逆变换还原成空间域图像。形态学操作以集合论为基础，靠结构元素和目标区域之间的膨胀、腐蚀等运算探测并修正几何形状。边缘检测的思路则是抓住灰度一阶梯度的极大值或二阶导数的过零点，亮度突变的区域被标定出来。本系统集成的34种算法，组织的模块正是按上述处理范式来划分的。
[97] (Normal) 卷积是空间域滤波背后的数学基础。把图像记作f、滤波核记作w，二维卷积的做法是：w在f上按步长逐位平移，每停在一个位置，核内权重就和对应邻域像素做乘积并求和，求出的结果写到输出图像对应位置的像素上。从严格意义上讲，核得先旋转180°，之后才轮到上述加权求和，这才是完整的卷积定义。滤波表现出什么性质，取决于滤波核的取值：服从二维高斯分布的高斯核中心大、四周小，平滑去噪是它的常见用途；取值带正负项的拉普拉斯核，则更多出现在锐化和边缘增强里。直方图承担统计图像灰度分布的任务，图像中各灰度级出现的频数都由它给出，直方图均衡化、Otsu阈值分割等算法的分析基础正是它。图像灰度变化的方向和快慢由梯度刻画，边缘检测的两类基本方法由一阶梯度算子（如Sobel）和二阶梯度算子（如Laplacian）构成。这些数学工具形式各异，合在一起却成了图像处理算法分析与实现的理论基石。图2-1给出了数字图像矩阵表示与二维卷积运算的示意。

[101] (Normal) OpenCV的全称是Open Source Computer Vision Library，作为开源软件库，它面向计算机视觉与图像处理领域。这个库支持的编程语言包括C++、Python、Java等好几种，跨平台能力也不错。库中集成的优化算法有数千个，滤波、几何变换、图像读写、目标跟踪、特征检测、机器学习等常用功能都涵盖在内。SIMD指令集和多线程并行计算的底层优化，使它在图像处理性能上有明显优势[29]。在国内，毛星云等人编著的《OpenCV3编程入门》系统介绍了OpenCV的基本架构与编程方法，是学习OpenCV的重要入门教材[30]；李立宗编著的《OpenCV轻松入门：面向Python》则针对Python语言详细讲解了OpenCV在图像处理中的应用，与本系统的技术路线高度契合[31]。
[102] (Normal) 算法覆盖面全这一点是最直接的，本系统要用到的34种算法，在它里面都有成熟而且经过优化的实现。它的Python接口封装也较为简洁，NumPy数组可以直接当输入输出，跟Streamlit这类Web框架对接的时候，不用额外的数据格式转换，集成成本降低。核心算法是用C/C++，经过了指令级优化，处理速度足以支撑实时交互，参数被用户调节之后，反馈能实时给出。
[103] (Normal) 从工程实践的角度看，直接调用OpenCV，而不是从零去实现算法，既保证算法的正确性和执行效率，也能让更多精力被投入到系统架构、交互设计和教学功能这些工作上。经过多年迭代和大量实际场景的检验，OpenCV核心算法的数值稳定性跟边界处理策略已经相当成熟了，卷积边界该怎么补值、数据类型怎么自动转换，它内部都有规范的实现，自行编码时容易冒出来的越界访问和精度损失问题，也就这样被绕开了。当然，OpenCV的封装并没有被系统全盘依赖。像Prewitt算子、锐化核、伽马查找表这类OpenCV没有直接提供的功能，就由系统借助NumPy自己去构造相关的核和查找表来解决，"复用成熟实现"和"自主实现关键细节"之间该怎么取舍，从这里面就体现出来了。
[104] (论文二级标题) Streamlit交互式框架
[105] (Normal) Streamlit是数据科学和机器学习领域里一个开源的Python框架。它内置的组件丰富，滑块（slider）、单选按钮（radio）、下拉菜单（selectbox）、标签页（tabs）、文件上传（file_uploader）这些都被包含在里面。
[106] (Normal) Streamlit与本系统进行结合，需求和它的特性是相应的。教学系统的交互，核心是"调节参数、观察结果"，这恰好是响应式模型支持的方式：用户拖动滑块，脚本重新执行，算法模块用新参数把图像重新处理，预览也就随之刷新了。另外它提供了会话状态（session_state）机制，缓存处理结果、记录性能数据这些都能实现。
[107] (Normal) 和其他Web开发方案比，本课题的应用场景里Streamlit优势比较突出。传统方案多基于Flask、Django等框架，前后端分离架构被普遍采用，后端路由与接口设计要开发者处理，前端组件也要开发者编写，技术栈跨度大，实现周期跟着拉长。Streamlit走的路线不同，交互控件和业务逻辑被统一封装在单个Python脚本里，完整的Web交互界面只凭纯Python代码就能生成，开发成本被明显压低。本系统的目标是算法演示和教学，“开发效率”与“交互能力”之间Streamlit取得了很好的平衡，定为技术选型再合适不过。
[108] (论文二级标题) Matplotlib可视化库
[109] (Normal) Matplotlib作为最常用的数据可视化库，本系统将三类可视化任务交给了它：图像的灰度直方图、处理前后的直方图对比，算法对像素分布的影响也就被直观地反映了出来；算法中间的处理步骤，会以图像网格的形式被展示出来，学生对算法内部流程的理解也因此得到了帮助；伽马校正曲线、频率能量分布这类数据曲线，同样由它画出，算法里的数学关系，以图形化的方式呈现。
[110] (论文二级标题) NumPy数值计算库
[111] (Normal) 在本系统里，OpenCV和NumPy能无缝衔接，图像底层靠NumPy数组来表示和传递的NumPy作为Python科学计算领域的根基性库，拿出了高性能的多维数组对象，跟数值运算相关的函数相当齐全。向量化运算的特性让批量操作图像像素的时候，不必再显式地去编写循环，处理的效率也跟着明显提升。傅里叶变换里幅度谱的求解和图像矩阵的归一化处理，这些环节统统都需要NumPy完成。
[112] (Normal) 从数据组织形式上看，OpenCV的图像对象是NumPy多维数组，两者之间切换几乎没什么开销，本系统的图像也一直以这种形态在内部流转，算法模块和显示模块交换数据因此变得很顺畅。Prewitt边缘检测算子落地的时候，本文先拿NumPy把卷积核矩阵构造出来，再交给OpenCV的filter2D函数去做卷积；傅里叶变换里频谱的搬移，则用NumPy的fftshift和ifftshift函数来处理。这种OpenCV和NumPy配合着干活的模式，贯穿了系统的始末，算得上是本系统技术落地的一个鲜明特色，Python科学计算生态的成熟与高效，也从这里面体现了出来。碰到复杂算法的时候，NumPy向量化的运算本事就起了关键作用。
[113] (论文二级标题) 深度学习与PyTorch
[114] (Normal) 卷积神经网络（CNN）是深度学习里最有代表性的模型。深度学习作为机器学习的一个重要分支，它的做法是把层次化的特征表示交给多层神经网络，让它自己从数据里自动学习。CNN的核心思路是局部感受野配上权值共享，用卷积运算把特征一层层地提取出来。一个典型的CNN，是由卷积层、池化层和全连接层堆叠起来的，卷积层里的卷积核是可学习的，局部特征靠它来提取；池化层负责做下采样，特征图的分辨率压低，平移不变性也就跟着增强；到了全连接层，提取出来的高层特征被映射成最终的输出类别。
[115] (Normal) 深度学习框架这块选用PyTorch。它作为一个开源的深度学习库，底层基于动态计算图，张量运算、自动微分和GPU加速。动态图机制带来的好处在于网络结构能在运行的过程里灵活搭建、也能灵活地调试，教学演示里想观察前向传播的完整过程，就变得容易了。配套的计算机视觉工具库torchvision里，MobileNetV2、DeepLabV3这类经典网络的结构定义能直接找到，连它们在ImageNet、COCO这些大规模数据集上预训练好的权重参数，也一并给出。
[116] (Normal) 深度学习模块中选用了MobileNetV2和DeepLabV3两个预训练网络，其设计基础是预训练模型与迁移学习。在ImageNet这类大规模数据集上完成预训练的网络，已经掌握了丰富的视觉特征，把它用作特征提取器迁移到新任务里，小样本甚至零样本的情况下也能取得较好的效果。其中MobileNetV2是面向移动端设计的，属于轻量级卷积网络，靠着深度可分离卷积，把参数量和计算量压得很低；DeepLabV3则是语义分割领域的代表性网络，空洞卷积配上空间金字塔池化，多尺度的上下文信息就被融合一起。
[117] (Normal) 在上面这些技术的支撑下，本文把深度学习算法模块构建了起来，图像分类、语义分割、图像超分辨率以及自定义图像分类这四类任务，配套的模型训练流水线也一并完成。

[142] (论文二级标题) 系统架构设计
[143] (Normal) 本系统的架构是模块化的四层结构，自底向上分别是工具层、算法层、可视化层和UI层，层与层之间职责分明、彼此解耦。最下面的工具层负责图像读写、色彩与数据类型转换、运行计时这类基础支撑工作；算法层依托OpenCV完成了七大类共34种图像处理方法，系统的核心计算由它承担；可视化层基于Matplotlib，绘制灰度直方图、把处理步骤按网格并排展示、生成指标曲线；最上面的UI层基于Streamlit搭建交互式界面，算法选择、参数调节、结果预览和教学资料展示都归它管。系统四层架构如图4-1所示。
[144] (Normal) 层与层之间的调用按单向依赖原则进行：上层能调用下层给出的接口，下层则不持有任何对上层的引用。UI层是系统的入口，用户输入由它采集，随后它依次调度算法层做处理、可视化层生成图表，再把结果渲染到界面上；算法层只管图像处理算法的实现，图像和参数字典通过统一的函数接口传进来，处理结果再统一返回；可视化层拿到算法层产出的中间结果后，生成相应的图表图像；工具层则向上述各层提供图像IO、格式转换和性能计时等基础服务。各层交互都走定义清晰的接口，比如所有算法函数都遵守同一个签名——接收图像（NumPy数组）和参数（字典）、返回处理结果（NumPy数组），这样一来，算法层可以脱离UI层独立开发和做单元测试。

[147] (Normal) 代码组织上，系统按分层思想划分出若干目录。算法层的六个算法模块、深度学习模块和可视化模块放在modules目录；深度学习模型的训练流水线则放在modules/training模块；UI层的侧边栏、预览、步骤可视化和教学面板四个界面模块放在ui目录；工具层的配置、图像IO和性能优化模块放在utils目录；教学资料数据存放在data目录；主程序app.py位于根目录，各模块的装配与调度都由它负责。
[148] (论文二级标题) 功能模块设计
[149] (Normal) 整个系统拆分成图像管理、算法处理、参数交互、可视化和教学面板这五个功能模块，这些模块彼此之间的配合依靠于主程序的会话状态来做统一调度：上游的模块会先把中间结果写进共享状态里，下游模块自动读取需要的内容，数据流转的链路是单向的，模块跟模块之间不会出现直接的依赖关系。具体分工上，图像的上传、读取、格式与色彩空间转换，还有处理结果的导出交给图像管理模块来负责；等到算法标识和参数组合被传进来之后，再由算法处理模块把对应的处理函数分发并执行；面对不同算法中各自的配置要求，参数交互模块动态生成调节控件；至于步骤对比网格、灰度直方图、指标曲线这些内容，都是从可视化模块里输出来的；教学模块来承担算法原理、代码、参数详解以及应用场景的展示。
[150] (Normal) 整个系统的数据入口是图像管理模块，它的核心职责有几项：接收用户上传的图像文件、把文件解码成标准的NumPy数组格式、对超大图像自动缩放，以及把处理结果编码成可下载的文件格式。算法处理模块靠算法注册表完成算法标识符到处理函数的映射，注册表以字典形式维护，键是算法标识符，值是对应处理函数的引用，这样设计之后，算法的新增与删除只需改动注册表，其他代码都不用动。参数交互模块根据算法参数定义动态生成调节组件，做到了“一套代码适配所有算法”的目标；可视化模块要和算法模块中的步骤函数配合，中间步骤的图像序列由算法模块给出，可视化模块再把这些图像序列绘制成统一的网格图。

[181] (论文二级标题) 滤波算法模块
[182] (Normal) 滤波算法模块实现了五种空间域方法：高斯滤波、中值滤波、均值滤波、双边滤波与方框滤波。高斯滤波拿二维高斯函数生成的权重核对图像进行卷积，核中心权重最高，随距离衰减，所以它在抑制加性高斯噪声的同时，整体灰度趋势也保留得较好；中值滤波把邻域像素的中值拿来替代中心像素，对椒盐噪声有极佳的去除效果，边缘同样能较好地保留；均值滤波是最简单的线性滤波器，计算速度快，但边缘会被模糊；双边滤波是在高斯滤波的基础上引入像素值相似度权重，空间距离和灰度差异被同时考虑，属于典型的保边去噪算法；方框滤波使用均匀权重核，是否归一化可由参数控制。
[183] (Normal) 下面挑高斯滤波作为示例，它的核心实现代码贴在这里：
[184] (Normal) def gaussian_blur(image, params):
    ksize = params.get("ksize", (5, 5))
    sigma_x = params.get("sigma_x", 1.0)
    if isinstance(ksize, int):
        ksize = (ksize, ksize)
    # 确保核大小为奇数
    ksize = (ksize[0] | 1, ksize[1] | 1)
    return cv2.GaussianBlur(image, ksize, sigmaX=sigma_x, sigmaY=sigma_x)
[185] (Normal) 在上面的实现当中，ksize参数决定卷积核的空间支撑范围，这个值一旦增大，参与加权的邻域随之变宽；sigma_x决定高斯分布的离散程度，它的取值增大以后，权重分布会变得更平坦。平滑强度是由这两者共同作用出来的，不过它们之间并不是独立叠加的关系。另外，对于用户传进来的核大小，系统做了奇数化处理，因为OpenCV要求高斯核必须是奇数，这一处理正好了满足这个要求。
[186] (Normal) 中值滤波表现对椒盐噪声的去除效果尤其突出。椒盐噪声在图像里表现为随机分布的极值像素点。均值滤波和高斯滤波是拿加权平均的方式来处理这类噪声的，极值很容易被扩散到邻域里去，形成局部的灰度畸变；而中值滤波属于非线性操作，它取的是邻域灰度的中位数，孤立的极值会被直接剔除掉，脉冲噪声得到抑制的同时，边缘的阶跃特性也被较好地维持住了。为了方便教学演示，系统的中值滤波步骤可视化，会先在示例图像上把椒盐噪声叠加上去，然后再把不同窗口大小下的去噪效果展示出来。
[187] (Normal) 双边滤波在五种方法中保边能力最强，代价是计算复杂度也最高，人像美颜、图像去噪等场合经常能见到它的身影[32]。传统高斯滤波只拿空间距离当权重，噪声压下去的同时，灰度阶跃处的边缘也难免被一并抹平；双边滤波把灰度差也拿来作第二权重因子，卷积权重由空间邻近性和灰度相似性两者共同敲定，区域内部的噪声被平滑掉，跨越边缘的混合却不会发生。落实到具体做法上，它在空间域权重以外再叠加一个像素值相似度权重：邻域像素与中心像素灰度接近，就照正常权重平滑；灰度差拉得大，就把该邻域像素的权重压下去，边缘因此受到保护。空间域滤波之外，去噪方法里还有以全变分模型为代表的变分去噪一路，做法是把能量泛函的最小化问题解出来，噪声去掉的同时边缘结构也保得比较牢[33]。滤波模块只收录了OpenCV提供的空间域滤波器，并未把去噪方法的完整谱系都装进来，之所以仍引入全变分等变分法模型，是想给图像去噪搭一个更完整的参照框架：一个靠局部邻域加权，一个靠能量泛函极小化，摆在一起看，不同去噪范式的内在联系与适用边界会更清楚。表5-2列出了各滤波算法的主要调节参数及其含义。

[190] (Normal) 直方图均衡化的做法，是借助累积分布函数把原始灰度分布映射成近似均匀分布，让像素占据更宽的动态范围，全局对比度由此得到提升，整体偏暗或灰度集中的图像尤其适合。CLAHE则先把图像分成若干子块，在各子块内分别做局部均衡化，同时用直方图剪切与重分配压住局部对比度的放大倍数，这样一来噪声放大被抑制住了，全局均衡化常见的过增强现象也能避免。除这两类之外，该模块还提供对比度与亮度调整、伽马校正、锐化及反锐化掩膜，合计六类算法。滤波与图像增强算法的处理效果对比如图5-2所示，图像增强算法的主要参数如表5-3所示。

[196] (Normal) def gamma_correction(image, params):
    gamma = params.get("gamma", 1.0)
    gamma = max(0.1, min(5.0, gamma))
    inv_gamma = 1.0 / gamma
    table = np.array(
        [(i / 255.0) ** inv_gamma * 255 for i in range(256)]
    ).astype(np.uint8)
    return cv2.LUT(image, table)

[202] (Normal) Canny算法是一种经典的多级边缘检测算法，处理流程依次为高斯滤波降噪、梯度幅值与方向计算、非极大值抑制细化边缘、双阈值检测与边缘连接四个步骤，输出的边缘连续且细化[34]。Sobel与Prewitt算子都建立在一阶导数之上：先算水平、垂直两个方向的梯度，再合成边缘幅值，二者的差别只在卷积核的权重设置。Laplacian算子走的是二阶微分路线，借助灰度二阶导数的零交叉把阶跃边缘的中心位置定出来。微分运算对高频分量有放大效应，二阶响应里噪声会被明显增强，所以该算子一般要与高斯平滑结合成LoG算子使用，或者放在Canny流程之前作前置环节，单独使用很容易出现大量伪边缘。Scharr算子可以看作Sobel算子的改进版本，旋转对称性更好，检测细小边缘时精度更高。以上Canny、Sobel、Laplacian、Scharr和Prewitt五种算法构成了边缘检测模块的全部内容，其主要参数如表5-4所示。

[205] (Normal) 梯度幅值的分级判定依靠双阈值机制。幅值比高阈值高的像素，会被标记成强边缘直接留下；而处在两个阈值之间的像素，则被标记为弱边缘，只有当它跟强边缘之间存在八连通路径的时候才会予以保留；至于低于低阈值的那些像素，就一律被抑制掉了。这种滞后策略，既把孤立的噪声响应压住，又把被局部低对比度打断的边缘连续性有效地恢复了过来。这两个参数系统都开放给用户去调节，方便观察阈值取值给边缘完整性以及噪声残留带来的影响。

[208] (Normal) Prewitt算子的水平方向卷积核是[[-1,0,1],[-1,0,1],[-1,0,1]]，每一行权重一致，算起来省事，代价是精度略逊。Sobel则不同，差分之前先对邻域做一次近似高斯的低通处理，靠这种加权换来更强的噪声抑制能力和更优的旋转对称性。两个算子都是可分离的，计算量处在同一量级。步骤可视化方面，水平方向梯度Gx、垂直方向梯度Gy以及由二者合成的梯度幅值被系统分别展示出来，“水平梯度检测垂直边缘、垂直梯度检测水平边缘”这条基本规律可以借此讲清楚。至于Laplacian算子，它属于二阶导数算子，对孤立像素和噪声的反应格外强烈，所以它的步骤可视化把高斯平滑后的图像放在前面、Laplacian运算结果放在后面，平滑预处理对二阶导数算子有多重要，由此被点明。另外，边缘检测和角点检测都归入图像局部特征提取的范畴，Harris等人提出的角点检测算法用图像局部灰度变化的结构张量来定位角点，算得上特征提取领域的经典方法[35]，两者一起构成图像特征提取的基础。

[210] (论文二级标题) 形态学操作模块
[211] (Normal) 形态学操作的基础是集合思想，它把结构元素当作探针来分析图像。这一模块共实现了七种操作：腐蚀和膨胀构成基本运算对，开运算与闭运算是二者的复合，形态学梯度、顶帽变换和黑帽变换则是从前者派生出的差分操作。具体地说，只有当结构元素完全包含于前景时，腐蚀才把中心点保留下来，细小目标因此可以被消除，纤细连接也能断开；膨胀恰好相反，只要结构元素与前景存在交集，中心点就被置为前景，孔洞得以填充，邻近物体得以连接。开运算用来去除孤立噪声点、平滑目标轮廓，闭运算用来填补前景内部的小孔。形态学梯度取膨胀与腐蚀之差，提取的是边界；顶帽是原图与开运算之差，亮于邻域的细微结构被它提出来；黑帽是闭运算与原图之差，提出的是暗于邻域的细微结构。边缘检测与形态学操作的处理效果对比如图5-3所示，形态学操作的主要参数如表5-5所示。
[212] (Normal) 结构元素是形态学运算的探针，操作的几何选择性就由它的形状与尺度决定。系统借助cv2.getStructuringElement构造出矩形、椭圆、十字三种结构元素，尺度交给ksize参数控制，用户只要调节这个参数，同一张图像在不同尺度下的响应差异就能看到。腐蚀与膨胀另外提供iterations参数，可执行多次连续运算。考虑到教学演示的需要，形态学模块执行前会先把图像二值化，再用图像序列的形式展示开运算、闭运算、形态学梯度等复合操作的中间步骤，复合操作按什么顺序执行、每一步起什么作用，用户都能直观把握。

[217] (论文二级标题) 阈值分割模块
[218] (Normal) 全局阈值、自适应阈值和Otsu二值化，这三种分割算法构成了阈值分割模块。全局阈值拿一个固定阈值把像素划成前景和背景，实现简单，但光照不均匀的图像很难用它处理好；自适应阈值不一样，它依据每个像素邻域的统计值动态算出局部阈值，光照分布不均的场景也能有效应对；Otsu算法走的是另一条路，遍历所有可能的阈值，把使类间方差最大的那个挑出来，阈值因此可以自动选取，灰度直方图呈双峰分布的图像最为适用[36]。阈值分割算法的主要参数如表5-6所示。
[219] (Normal) 在自适应阈值里面，判定基准换成了局部统计量。对于每一个像素，系统都会去取它block_size邻域内像素的高斯加权均值，然后再减去常数C，也就得到了该点专属的阈值𝑇(𝑥,𝑦)。block_size决定的是局部窗口的感受野，它的取值越大，阈值图就越平滑，算法也会慢慢退化回全局阈值，适应局部照度变化的能力也就跟着变差；常数C的作用是把判定边界整体地偏移一下，C变大就相当于把门槛放低，前景区域也就随之扩张了。
[220] (Normal) 最大化类间方差，是Otsu算法的核心思想。阈值t把图像像素分成前景和背景两类，类间方差越大，两类灰度差异越大，分割效果也就越好。该算法把0到255所有可能的阈值都遍历一遍，逐一算出对应的类间方差，使类间方差最大的那个被选作最优阈值。整个过程不需要人工设定阈值，所以它对双峰直方图图像有很好的自适应性。步骤可视化里，系统会显示Otsu算法算出的最优阈值，再拿它与64、128、192等固定阈值的结果做对比，自动阈值选取的意义，学生由此能够理解。
[221] (Normal) Otsu二值化的关键实现代码列在下面：
[222] (Normal) def otsu_threshold(image, params):
    gray = to_grayscale(image)
    _, result = cv2.threshold(
        gray, 0, 255,
        cv2.THRESH_BINARY + cv2.THRESH_OTSU
    )

[223] (Normal) OpenCV里，Otsu算法的启用靠阈值化类型标志：cv2.THRESH_OTSU与具体的阈值化类型按位或组合，一并传给cv2.threshold即可。这时调用者传进去的阈值参数不再起作用，函数会依据图像灰度直方图的统计分布，自动搜索类间方差最大的最优阈值，再把它作为第一个返回值回传。系统另外还实现了get_otsu_threshold_value函数，Otsu算法算出的阈值数值可以用它单独提取出来，步骤可视化时这一数值被标注在图像标题上，自动阈值与手动设定阈值的差异，用户一眼就能对比。

[225] (论文二级标题) 图像变换模块
[226] (Normal) 图像变换模块的内容分两类，一类是几何变换，另一类是频域变换。几何变换借助坐标映射去改变像素位置：缩放与旋转分别由cv2.resize、cv2.warpAffine完成，仿射变换则用三点确定的一个2×3矩阵，把平移、旋转与缩放的复合形变统一描述出来，直线的共线性与平行性在此过程中保持不变。傅里叶变换把图像从空间域映射到频率域，图像被分解成不同频率正弦分量的叠加，低频分量对应灰度变化缓慢的平滑区域与整体结构，高频分量对应边缘、纹理与噪声，在频域里用掩模做低通平滑、高通锐化因此成为可能。该模块用cv2.dft完成傅里叶变换，对幅度谱取了对数，可视化效果更好，同时还提供低通和高通滤波功能，帮助用户理解频率域滤波的概念。图像变换算法的主要参数如表5-7所示。
[227] (Normal) 傅里叶变换的实现过程中，系统会先把灰度图像转换成float32类型，再调用cv2.dft去做离散傅里叶变换，拿到的结果里包含着实部和虚部；接着用numpy的fftshift把频谱象限重新排一下，零频就被移到了显示中心；幅度谱则由cv2.magnitude算出来，取对数把动态范围压缩之后，低频和高频成分能看得清楚；处理完的数值，再被归一化到0到255的灰度范围里用来显示。频率域的可视化功能，不只是展示幅度谱，低通、高通滤波也有演示：频谱中心的低频成分要是被保留下来，图像也就得到了平滑；而频谱边缘的高频成分被保留下来之后，得到的就是边缘提取后的结果。

[250] (Normal) def process_image(image, algorithm_key, params):
    algo_func = ALGORITHM_FUNCTIONS.get(algorithm_key)
    if algo_func is None:
        return image, 0.0
    with Timer() as timer:
        try:
            result = algo_func(image, params)
        except Exception as e:
            return image, 0.0
        else:
            if result.dtype != np.uint8:
                result = np.clip(result, 0, 255).astype(np.uint8)
    return result, timer.elapsed_ms
[251] (Normal) 算法注册表ALGORITHM_FUNCTIONS负责把算法标识符映射到具体的处理函数，上下文管理器Timer测量处理耗时，异常也被捕获并处理，这些都是在引擎内部完成。另外，主程序还会去比较当前算法和参数有没有发生变化，据此来判断要不要重新执行处理，避免Streamlit脚本重复运行所带来的冗余计算。
[252] (Normal) 交互模块中参数面板的动态生成，每个算法在配置文件config.py里，都有一份系统维护的默认参数表DEFAULT_PARAMS，而参数的类型、取值范围还有调节组件形式则在教学资料里另外做定义。生成面板的时候，系统会逐项读取当前算法的参数定义，然后再按照类型去选Streamlit对应的组件渲染出来，新增算法只要把参数定义补齐，界面会自动出现。
[253] (Normal) Streamlit的脚本只要发生一次用户交互就会从头执行，中间结果要是不缓存进会话状态，重复的算法计算势必会带来多余的开销。正是出于这一考虑，原始图像、处理结果、当前算法、当前参数以及性能统计等状态信息，都被系统交给session_state机制去保管了。处理结果存下来之后，系统还会比对参数有没有发生变化，确实改变了才会重新调用算法处理函数，重复计算也就由此显著减少了。性能统计器ProcessingTimer则会把最近若干次处理的时间记录下来，平均耗时、最大耗时等性能指标也借此实时呈现出来，用户能够直观地了解系统的响应情况。
[254] (论文二级标题) 教学模块
[255] (Normal) 内容被分成算法原理、核心代码、参数详解还有应用场景这四个部分。核心思想和数学基础是由原理部分用Markdown来描述；关键实现被抽取到代码部分，语法高亮也予以保留；参数的含义以及它对处理效果的影响，在参数部分逐项做解释，当前的取值还跟控件联动，实时回显出来；工业与学术界的典型用途则归到场景部分里。全部资料都统一拿算法标识当键集中存放，界面再按当前算法索引来完成渲染，理论讲解、代码实现和参数实践这三者由此实现了有机结合。
[256] (Normal) 教学资料是以结构化字典的形式存放在系统的data.teaching_content模块里，名称、所属类别、原理说明、代码片段、参数定义列表以及应用场景列表等字段构成了每个算法的条目。得益于这种数据结构化的设计，教学面板和参数面板得以共享同一份数据源：调节组件是由参数面板依据参数定义列表动态生成的，教学内容由教学面板依据原理说明和代码片段来渲染的。除此之外，系统还给出了快速入门指南和算法速查表，新用户借此能够快速掌握系统的使用方法以及算法分类结构。
[257] (Normal) 学习路径的推荐顺序，依据的是算法之间的依赖关系。系统把初级路径安排成"滤波—增强—边缘检测—形态学"：空间滤波是以卷积和邻域运算为基础的，以便于梯度算子的理解；灰度直方图和像素映射一方面是增强的核心内容，另一方面也是阈值处理的前置知识；形态学操作的对象是二值图像的形状结构。进阶路径则包含双边滤波、反锐化掩膜、傅里叶变换和Otsu二值化，这几个算法的共同点是要用到前面的基础知识，参数也都有明确的物理含义。
